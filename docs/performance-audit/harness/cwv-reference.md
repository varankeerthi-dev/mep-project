Google's official status definitions list good ranges of LCP ≤2.5 s, INP ≤200 ms, and CLS ≤0.1. Source: https://developers.google.com/search/docs/appearance/core-web-vitals and https://support.google.com/webmasters/answer/9205520?hl=en (both fetched 2026-10-02). The Search Console Core Web Vitals report is based on actual user Chrome UX Report field data; group LCP and INP are reported as values that 75% of visits meet or beat, and group CLS reflects the 75% visit cutoff. This audit's Chromium measurements are synthetic lab data, not field data and not a p75 sample; compare them to those cutoffs only as reference thresholds, never claim field p75 status.
