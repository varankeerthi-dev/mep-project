Entry Form

Complete style guide for the Item Editor entry forms — inputs, buttons, tables, sections, and interactions. Copy-paste ready for any junior developer.

⚠️ CSS Override Issue — Table Cell Padding

Tailwind classes like py-[16px] on <td> / <th> elements don't always apply because of global CSS resets (* { padding: 0 !important; }) and browser default table styles competing in the cascade.

✅ Fix — Use Inline Styles for Table Cells

Always use style={{ padding: '16px 16px' }} on <th> and <td>. Inline styles have the highest specificity and bypass all CSS class conflicts.
